# System page (INTERFACES AND SERVICES)

Diagnostic detail — interface addresses and systemd service states.
Auto-refreshed every 5s.

## Interfaces

| Column | Meaning |
|--------|---------|
| Iface | Interface name. |
| State | Operational state: `UP` (green), `absent` (grey/off), other (amber). |
| Addr | Comma-separated addresses, or `—`. |

## Services

Each row is a systemd unit and its state: `active` (green), otherwise off/grey.
